# UI and Accessibility Checklist

## Visual

- [ ] Typography is consistent with the design system.
- [ ] Important states do not rely on color alone.
- [ ] Contrast has been reviewed for critical content.
- [ ] Layout works across representative screen sizes.

## Interaction

- [ ] Interactive controls have meaningful labels.
- [ ] Icon-only controls are accessible.
- [ ] Focus/traversal order is logical.
- [ ] Touch targets are comfortably usable.

## Accessibility

- [ ] Large text settings have been tested.
- [ ] Screen-reader semantics have been reviewed for critical flows.
- [ ] Error and validation messages are understandable.
- [ ] Motion does not prevent users from completing important actions.

## Design system

- [ ] Shared spacing, typography, color, and component tokens are used.
- [ ] Component states are defined consistently.
