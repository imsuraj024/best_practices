# Security Policy

## Scope

This repository contains Flutter engineering guidance and example code.

Do not commit real credentials, API keys, certificates, private keys, tokens, customer data, or other sensitive information.

## Reporting a security issue

If you discover a security problem in repository content, avoid publishing sensitive details in a public issue. Contact the repository owner privately through GitHub.

## Example-code requirements

Examples should:

- Use placeholders for secrets.
- Demonstrate secure storage for sensitive local data.
- Avoid logging credentials or personal data.
- Clearly identify security-sensitive trade-offs.
